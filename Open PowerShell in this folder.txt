Then run:

npm.cmd run build
npm.cmd run dev
Open the local URL shown, usually:
http://localhost:5173
Before live submissions work, configure Firebase:
Go to Firebase Console → create project.
Add a Web App and copy its configuration values.
In the project folder, copy .env.example to .env.
Paste the Firebase values into .env.
In Firebase:Enable Firestore Database in Production mode.
Enable Authentication → Email/Password.
Create one or more admin users in Authentication.
Open Firestore Rules, paste the contents of firestore.rules, then publish.

Restart the dev server after adding .env:
npm.cmd run dev
Use:
Participant site: http://localhost:5173
Admin dashboard: http://localhost:5173/admin
Finally, deploy to Vercel:
npm.cmd install -g vercel
vercel
In Vercel Project Settings → Environment Variables, add the same six VITE_FIREBASE_* values from .env, then redeploy.
